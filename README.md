# 区間タイマー PWA

## GitHub Pagesへの設置
1. このZIPを展開します。
2. GitHubで新しいリポジトリを作成します。
3. 展開したファイルをリポジトリ直下へアップロードします。
4. Settings > Pages > Build and deployment で Deploy from a branch を選択します。
5. Branchを main、フォルダーを /(root) にして保存します。
6. 発行されたURLをiPhoneのSafariで開きます。
7. 共有 > ホーム画面に追加 > ウェブアプリとして開く > 追加 を選択します。

## 注意
- タイマー設定はlocalStorageに保存され、サーバーには送信されません。
- iPhoneで画面ロックや別アプリへの切替をすると、Webアプリのタイマーや音が停止・遅延する場合があります。
- 使用中は画面を表示したままにし、消音モードを解除してください。
